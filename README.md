# ArrangeLab

Static public package for ArrangeLab.

- Open the app in the browser and load an Ableton `.als` file.
- Processing happens locally in the browser.
- No file is uploaded to a server.
- `hardware/` is a separate Web MIDI companion, reached from the discrete Hardware entry in the app.

This repository is intentionally minimal and should contain only:

- `index.html`
- `hardware/`
- `.nojekyll`
- `README.md`
