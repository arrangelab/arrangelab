Arrangement Overview

Las escenas entran en compases 8, 16, 24… El marcador indica cuándo entra la escena; el Program Change se envía un compás antes para que la MC-707 lo cuantice. Click en la tira superior agrega una escena al múltiplo de 8 más cercano.

Scene Changes

Program Change 0–127 por Control Channel. Las escenas entran cada 8 compases; el envío ocurre un compás antes.

Estructura

Cargá un .als para empezar. El largo del tema sale de sus locators y de ningún otro lado: sin Set no hay timeline, no hay lanes y PLAY queda apagado. Los controles CC de abajo sí funcionan: son manuales y no dependen del arreglo.
Round
Las secciones son los locators del Set y el último marca el final, no una sección más. Tocá una para elegirla: se resalta también en las automation lanes y se puede renombrar, estirar desde su borde derecho, mover, duplicar o borrar. Los puntos de automatización viajan con su sección: si estirás el break, el barrido que lo cruzaba lo sigue cruzando entero, y lo que venía después se corre. BARS nunca se escribe: es la suma de las secciones.
