Instrumentos por canal

Cada instrumento suena por un solo canal: tocarlo en otra fila lo mueve. El Set dice que por 9/10 entra «HHs», pero no cuál de los once instrumentos de la TR-8S es — eso lo decidís acá una vez y queda guardado con el preset.

Preset

El preset se guarda en este navegador. `EXPORT JSON` baja el mismo proyecto como archivo, para moverlo de maquina o respaldarlo; `IMPORT JSON` lo vuelve a cargar.

Arrangement Overview

Las escenas entran en compases 8, 16, 24… El marcador indica cuándo entra la escena; el Program Change se envía un compás antes para que la MC-707 lo cuantice. Click en la tira superior agrega una escena al múltiplo de 8 más cercano.

Scene Changes

Program Change 0–127 por Control Channel. Las escenas entran cada 8 compases; el envío ocurre un compás antes.

Automation Lanes

MVP inicial: CC7 Volume, CC74 Cutoff o cualquier CC custom.

Live CC Control
